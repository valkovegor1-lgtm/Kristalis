# Перенос CRYSTALIS на другой аккаунт Netlify (вместе с данными)

Код не привязан к аккаунту: все адреса относительные, ключей внутри нет. Всё, что нужно, — выложить проект и (по желанию) подтянуть данные.

## 1. Выложить проект на новый аккаунт
Функциям нужен `npm install` (пакет `@netlify/blobs`), поэтому загружай **не простым перетаскиванием папки**, а одним из способов:

**Через GitHub (проще всего)**
1. Создай репозиторий на GitHub и залей туда содержимое папки проекта (рядом лежат `netlify.toml`, `package.json`, `public/`, `netlify/`, `seed/`).
2. На новом аккаунте Netlify: Add new site → Import an existing project → выбери репозиторий. Настройки подтянутся из `netlify.toml` (publish — `public`, functions — `netlify/functions`).

**Через Netlify CLI**
```
npm i -g netlify-cli
netlify login          # войти в НОВЫЙ аккаунт
cd папка-проекта
npm install
netlify init           # создать новый сайт
netlify deploy --prod
```

## 2. Переменные окружения (Site configuration → Environment variables)
| Переменная | Для чего |
|---|---|
| `DEV_LOGINS` | логин(ы) главного разработчика, через запятую (по умолчанию `1111`) |
| `DEV_PASSWORD` | пароль главного разработчика (по умолчанию `1111` — **смени**) |
| `DEV_NAME` | имя разработчика (по умолчанию «Егор») |
| `YADISK_LOGIN`, `YADISK_APP_PASSWORD`, `YADISK_FOLDER` | резервные копии на Яндекс Диск (см. BACKUP_YANDEX_DISK.md) |
| `BACKUP_INTERVAL_MIN` | как часто делать автокопию (по умолчанию 60) |

После добавления переменных сделай redeploy.

## 3. Перенести данные пользователей — любой из двух способов
**А. Через Яндекс Диск.** На старом сайте нажми «Сделать копию сейчас» (вкладка «Разработчик»). На новом сайте задай **те же** `YADISK_*` — при первом открытии сайта данные подтянутся автоматически (или нажми «Восстановить из копии»).

**Б. Файлом внутри проекта.** На старом сайте: «Разработчик» → «Скачать снимок (.gz)». Положи файл в папку `seed/` под именем `crystalis-latest.json.gz` и задеплой проект. На пустом новом сайте данные загрузятся сами при первом запросе.

Автоподтягивание срабатывает **один раз** и только если на сайте ещё нет пользователей, поэтому уже работающий сайт данными не перезаписывается. Если данные нужно залить поверх — кнопка «Восстановить из копии» (только главный разработчик).

## 4. Что переносится
Аккаунты и пароли (хэши), галереи и коллекции, обучение, друзья, баланс Сойн, лоты рынка, личные и общий чаты, уведомления, сообщения разработчика, журнал.
**Не переносится:** активные сессии (пользователям придётся войти заново), статусы «в сети» и картинки, отправленные в чатах (чтобы снимок оставался лёгким).

## Важно
- Снимок содержит хэши паролей и личные переписки — храни его приватно (не публикуй репозиторий с файлом из `seed/` как открытый).
- Если данных очень много (десятки МБ), выгрузка в рамках одного вызова функции (лимит ~10 с) может не уложиться — тогда используй локальную версию (`node main.js`) или напиши, перенесём на базу данных.
