# Резервные копии базы на Яндекс Диск

1. Яндекс ID → Безопасность → **Пароли приложений** → создать пароль типа **«Файлы WebDAV»**. Основной пароль от Яндекса не используй.
2. Добавь переменные окружения (Netlify: Site configuration → Environment variables; локально — перед `node main.js`):

| Переменная | Значение |
|---|---|
| `YADISK_LOGIN` | логин или почта Яндекса |
| `YADISK_APP_PASSWORD` | пароль приложения из шага 1 |
| `YADISK_FOLDER` | папка на Диске (по умолчанию `CRYSTALIS-backup`) |
| `BACKUP_INTERVAL_MIN` | как часто копировать, минут (по умолчанию 60, минимум 10) |

3. Передеплой сайт.

**Что происходит**
- На Диск кладутся два файла: `crystalis-latest.json.gz` (обновляется каждый раз) и `crystalis-ГГГГ-ММ-ДД.json.gz` (одна копия в сутки).
- Netlify: автокопию запускает первый запрос после истечения интервала. Кнопки «Сделать копию сейчас» и «Восстановить из копии» — в Панели разработчика (восстановление только у главного разработчика).
- Локальный `main.js`: копия по таймеру; если файла `data/db.json` нет (например, диск хостинга очистили), база сама восстановится из `crystalis-latest.json.gz` при запуске.
- В копию не входят сессии, статусы «в сети», служебные метки и картинки из чатов.
- В копии лежат хэши паролей — храни папку приватной.
