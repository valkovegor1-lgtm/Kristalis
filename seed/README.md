Сюда кладётся файл **crystalis-latest.json.gz** — снимок всех данных участников.
При первом запуске на пустом сайте приложение само загрузит его в хранилище.

Как получить снимок: войди разработчиком (главным) → вкладка «Разработчик» → «Скачать снимок (.gz)».
Если снимок больше ~4,5 МБ — возьми crystalis-latest.json.gz с Яндекс Диска (папка CRYSTALIS-backup).
